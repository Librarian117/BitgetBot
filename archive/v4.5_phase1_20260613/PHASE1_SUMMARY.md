## 已识别问题

### 🔴 Critical（导致亏损的直接原因）

1. **规则引擎止损过松** — 首小时无止损保护，亏损达 -50% 才熔断
2. **AI 退出审核完全失效** — 所有 AI_EXIT_DECISION 显示"调用失败-默认通过"（全部 HOLD）
3. **AUTO_SL 阈值 -30%** — 浮亏 30% 才自动止损，过晚
4. **BNB LONG -140.84% 爆仓** — 多头方向持续亏损，但未被 Direction Block 拦截

### 🟡 High（系统性风险）

5. **方向失衡** — 多头 0% 胜率仍被允许开仓；做空 59.3% 胜率但亏损（平均亏损过大）
6. **币种集中度风险** — DOT 12 连败但未被限制，单币种亏损占总量 222%
7. **量比过滤过严** — ADX 16 + 量比 1.5 组合导致 87% 周期无信号
8. **重复 PnL 记录** — strategy_performance.json 中同一交易重复多达 5 次

### 🟠 Medium（技术债务）

9. **沙箱模式硬编码** — exchange_interface.py `set_sandbox_mode(True)` 无法切换实盘
10. **静默异常吞掉 25+ 处** — 关键 API 错误仅记录 DEBUG 级别
11. **开仓时间重启丢失** — 僵尸仓退出和 AUTO_SL 依赖的开仓时间在重启后重置
12. **runtime_params.json 覆盖 TP 为 5.0x ATR** — 远高于 .env 的 2.0-3.0x

## 关键教训

1. **止损是第一优先级** — 平均亏损（-160）是平均盈利（+84）的 1.9 倍，只要把亏损控制在盈利的 1x 以内就能盈利
2. **方向过滤不能只依赖 RSI** — LONG 方向 0% 胜率说明 Direction Block 的 RSI 条件（effective_oversold * 0.7 ≈ 28）仍然不够严格，或者根本不应该在下跌趋势中做多
3. **币种层面需要硬止损** — DOT 12 连败应当触发币种级暂停
4. **AI 不是决策者但应该是"哨兵"** — AI 退出审核不应完全移除，应在 API 正常时辅助判断，API 失败时回退到收紧的规则引擎
5. **单币种对冲失效** — LINK 同时持有 LONG+SHORT，ALLOW_HEDGE=false 未生效（可能是先后开仓）
